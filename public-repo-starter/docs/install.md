# Installing Lunara

1. On the [latest release](https://github.com/ankitkhatrik6/lunara-releases/releases/latest),
   download the APK (`Lunara-<version>-release.apk`).
2. Open it. Android asks you to allow installs from your browser/file manager once — allow it.
3. If Play Protect shows an "unknown developer" warning: that is expected for an app installed
   outside the Play Store. Tap **More details → Install anyway**. (A future signed release from
   the same key keeps updating cleanly afterwards.)
4. No sign-in, no setup. Open a shared `lunara.ankitak.com.np` link and it lands straight in
   the app.

## Updating

The app checks the public releases page for new versions and offers them in Settings. Updates
install over the existing copy as long as they come from the same signing key — which every
release here does.
