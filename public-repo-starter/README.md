# Lunara — releases & docs

Lunara is a GPL-3.0 Android music player: sign-in-free listening with a premium Material You
interface. This repo is its public face — **releases and documentation only**.

- **Get it:** [latest release](../../releases/latest) (APK + AAB)
- **All versions:** [releases](../../releases)
- **Site:** https://lunara.ankitak.com.np

## What lives here

- `README.md` — this file
- `LICENSE` — GNU GPL-3.0, your rights to the app
- `docs/` — user guides (installing, sharing, link previews)
- `notes/<tag>.md` — the changelog for each release (copied automatically by promotion)

Development happens in a private repo; only builds you see published here were tested and
promoted by hand. Each published release carries its `Lunara-<version>-source.tar.gz` alongside
the APK/AAB, which is the exact code that build came from.
